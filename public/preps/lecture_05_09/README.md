# Лекция 5.09: оценки и сортировки

Код: [quicksort](01_quick.cpp), [merge sort](02_merge.cpp), [counting sort](01_counting.cpp), [radix чисел](02_radix_numbers.cpp), [radix записей](03_radix_records.cpp), [radix строк](04_radix_strings.cpp). Quicksort и merge sort ранее были названы владельцем как изученные, но их точная привязка к этой лекции не сообщалась: здесь они размещены как примеры сортировок сравнением.

Подробные разборы: [сортировки сравнением](COMPARISON_SORTS.md) и [линейные сортировки](LINEAR_SORTS.md). Исторический [проверочный сценарий](verify.py) охватывает также [карманную сортировку из лекции 12.09](../lecture_12_09/05_bucket.cpp).

Запуск из корня репозитория: `c++ -std=c++17 public/preps/lecture_05_09/01_counting.cpp -o /tmp/counting && /tmp/counting`. Форматы ввода различаются и приведены в исходниках и подробных разборах.
