# Лекция 3.10: декартово дерево и запросы

- [implicit_treap.cpp](implicit_treap.cpp): последовательность с неявным ключом, операции `insert pos x`, `erase pos`, `reverse l r`, `sum l r`. Индексы с нуля, отрезок `[l,r)`; ввод — число команд и команды. Приоритеты псевдослучайны, ожидаемое время операции `O(log n)`.
- [01_segment_tree.cpp](01_segment_tree.cpp): дерево отрезков для суммы и присваивания элемента.
- [02_fenwick.cpp](02_fenwick.cpp): дерево Фенвика для суммы и прибавления к элементу.

Для двух последних программ формат и примеры — в [RANGE_QUERIES.md](RANGE_QUERIES.md). Обычное декартово дерево с явным ключом находится в [лекции 19.09](../lecture_19_09/02_treap.cpp).

`ImplicitTreap<T>` поддерживает сложение значений типа `T`; `append(first, last)` добавляет диапазон входных итераторов, а `copyTo(out)` выдаёт последовательность через выходной итератор.
