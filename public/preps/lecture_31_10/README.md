# Лекция 31.10: поиск подстроки

Ввод примеров: первая строка содержит непустой образец, вторая строка содержит текст. Выводятся начальные индексы всех вхождений с нуля, по одному в строке. Перекрывающиеся вхождения учитываются. Пустой образец в этих примерах не ищется.

- [Обычный KMP](01_kmp.cpp) ищет все вхождения через префикс-функцию. Его поиск обрабатывает текст за `O(n)` после построения префикс-функции за `O(m)`.
- [KMP реального времени](kmp_realtime.cpp) строит таблицу переходов по байтовому алфавиту. После подготовки каждый новый байт текста обрабатывается за `O(1)`, в том числе при серии несовпадений. Простая версия работает со строками байтов, обобщённая принимает диапазон символов и функцию перевода символа в индекс алфавита. Подготовка и память требуют `O(mσ)`, где `σ` равно 256 в простой версии.
- [Бойер и Мур](boyer_moore.cpp) сравнивает образец справа налево и использует оба правила сдвига, плохого символа и хорошего суффикса. Простая версия работает с байтовыми строками, обобщённая принимает итераторы случайного доступа. Эта учебная версия не использует правило Галиля, поэтому линейная оценка для неё здесь не заявлена.

`m` обозначает длину образца, `n` обозначает длину текста. Вариант с полной таблицей переходов удобен для разбора обработки потока, но таблица размером `256 × (m + 1)` может быть слишком большой для длинного образца. Формулировка «KMP реального времени» в сообщении о лекции не уточняет конкретную технику построения автомата, здесь показан один вариант с постоянным временем обработки байта после подготовки.

Источники для устройства алгоритмов: [статья Кнута, Морриса и Пратта](https://www.cs.jhu.edu/~misha/Spring23/Knuth77.pdf), [статья Бойера и Мура](https://www.cs.utexas.edu/~moore/publications/fstrpos.pdf). Список тем лекции взят из сообщения владельца репозитория.
