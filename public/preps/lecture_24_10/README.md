# Лекция 24.10: хеширование и строки

- [01_hash_table.cpp](01_hash_table.cpp): коллизии разрешаются цепочками. Ввод: число команд, затем `+ слово` или `? слово`.
- [open_addressing.cpp](open_addressing.cpp): линейное пробирование с маркерами удалённых ячеек и расширением таблицы. Ввод: число команд, затем `+ x`, `- x`, `? x` для целых.
- [naive_substring.cpp](naive_substring.cpp): наивный поиск всех вхождений; первая строка — непустой образец, вторая — текст, вывод индексов.
- [prefix_function.cpp](prefix_function.cpp): отдельная префикс-функция, дополнительный пример. Одна строка на входе, массив значений на выходе.
- [02_kmp.cpp](02_kmp.cpp): поиск Кнута — Морриса — Пратта через префикс-функцию; две строки на входе, индексы вхождений на выходе.
- [03_z.cpp](03_z.cpp): Z-функция; строка на входе, значения на выходе.

Подробности старых примеров — в [HASHING_STRINGS.md](HASHING_STRINGS.md). В лекционном перечне «основная функция препроцессинга» не названа, поэтому префикс-функция и KMP не приписываются ей как установленный факт.
