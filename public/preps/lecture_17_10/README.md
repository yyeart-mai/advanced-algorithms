# Лекция 17.10: B-деревья

[04_b_tree.cpp](04_b_tree.cpp) содержит простой вариант со вставкой и поиском и шаблонное `BTreeGeneric<Key, Degree, Compare>` со вставкой, поиском и удалением. `Degree` — минимальная степень, не меньше 2. При `Degree = 2` получается 2-3-4 дерево.

Ввод программы: число команд, затем `+ x`, `- x`, `? x`; поиск выводит `YES` или `NO`. Пример: `5`, `+ 3`, `+ 7`, `? 3`, `- 3`, `? 3` → `YES`, `NO`.

Операции работают за `O(log n)` уровней при фиксированной степени. Внутри узла поиск позиции здесь линейный по числу ключей; для переменной большой степени эту стоимость нужно учитывать отдельно.
