# Учебный контекст

Курс: **«Продвинутые алгоритмы и дискретный анализ»**. Язык решений: **C++**.

## Изученные темы

Список зафиксирован со слов владельца репозитория. «Изучена» здесь означает, что тема уже проходилась на курсе; степень владения и набор конкретных методов не подтверждены.

| Раздел | Темы |
| --- | --- |
| Линейные сортировки | Сортировка подсчётом, поразрядная сортировка, bucket sort (сортировка корзинами) |
| Сортировки сравнением | Quicksort (быстрая сортировка), merge sort (сортировка слиянием) |
| Деревья поиска | AVL-деревья, красно-чёрные деревья, декартовы деревья, B-дерево |
| Структуры для запросов | Segment Tree (дерево отрезков), Fenwick Tree (дерево Фенвика) |
| Хеширование и строки | Хеш-таблицы, алгоритмы поиска подстроки, Z-алгоритм |

## Как использовать этот контекст

- При решении новых задач сначала сверять условие, ограничения, формат ввода и вывода с нужной темой. Список выше не задаёт конкретную реализацию или допустимую сложность.
- Если задача связана с прежней, сверяться с [архивом задач и решений](SOLVED_TASKS.md). Статус принятия указан отдельно от наличия исходника или условия.
- Для линейных сортировок в репозитории есть [учебный разбор и примеры](public/linear_sort_prep/README.md). Это материал для подготовки, а не перечень сданных задач.
- Примеры по остальным темам: [сортировки сравнением](public/comparison_sort_prep/README.md), [деревья поиска](public/tree_prep/README.md), [запросы на отрезке](public/range_query_prep/README.md), [хеширование и строки](public/hashing_strings_prep/README.md).
- При появлении новых тем дополнять таблицу; при подтверждении решения пополнять журнал.
