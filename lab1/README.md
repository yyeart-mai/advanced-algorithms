# Словарь PATRICIA

Для сборки нужен компилятор C++11 и `make`. Для проверок нужен Python 3. Команды ниже запускаются из корня репозитория.

```sh
make -C lab1
make -C lab1 check
```

Сборка создаёт статическую библиотеку `lab1/build/libpatricia.a` и консольную программу `lab1/build/dictionary`. Чтобы использовать библиотеку в другой программе, подключите `lab1/src/patricia.hpp` и скомпонуйте программу с `libpatricia.a`.

`make check` прогоняет сценарии через консоль в оптимизированной и отладочной сборках. Проверки сравнивают ответы с ожидаемыми, включая поток команд с фиксированным seed и независимым эталонным словарём. В отладочной сборке после команд вставки, удаления и файловых операций проверяются служебная голова, число узлов при обходе по нисходящим ссылкам и совпадение кандидата поиска с каждым посещённым узлом.
