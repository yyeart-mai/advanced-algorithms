# Деревья поиска

Каждый файл — отдельная программа C++17 с учебной реализацией **вставки уникальных целых ключей и поиска**. Ввод: число команд `q`, затем `+ x` (добавить) или `? x` (проверить). Вывод для `?`: `YES` или `NO`. Удаление и запросы порядковых статистик в этих примерах не реализованы.

| Файл | Инвариант | Сложность вставки/поиска |
| --- | --- | --- |
| [01_avl.cpp](01_avl.cpp) | Высоты левого и правого поддеревьев отличаются не более чем на 1 | `O(log n)` |
| [02_treap.cpp](02_treap.cpp) | Ключи образуют BST, псевдослучайные приоритеты — кучу | Ожидаемое `O(log n)`, худшее `O(n)` |
| [03_red_black.cpp](03_red_black.cpp) | Красный узел не имеет красного ребёнка, число чёрных узлов на путях одинаково | `O(log n)` |
| [04_b_tree.cpp](04_b_tree.cpp) | B-дерево минимальной степени 2: узел содержит от 1 до 3 ключей | `O(log n)` уровней; вставка в массив ключей узла здесь постоянна из-за фиксированной степени |

Пример: `5`, `+ 7`, `+ 3`, `? 3`, `? 4`, `? 7` → `YES`, `NO`, `YES`. Запуск: `c++ -std=c++17 -Wall -Wextra -pedantic 01_avl.cpp -o /tmp/avl && /tmp/avl`.

Для AVL проверьте последовательности `1 2 3` и `3 1 2`; для красно-чёрного дерева — перекраску дяди и оба вида поворотов; для B-дерева — разделение заполненного корня; для декартова — два независимых порядка ключей и приоритетов. Код `02_treap.cpp` использует фиксированное начальное состояние генератора ради воспроизводимости, а не криптографической случайности.
