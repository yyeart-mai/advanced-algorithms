# Профиль CPU при успешном поиске

Профиль снят с оптимизированного словаря на Mac при заполнении 100 000 ключами с общим префиксом и последующем повторении блока поиска. Вход содержит один блок вставок и 60 блоков по 100 000 успешных запросов. Команды подаются через канал, ответы направляются в `/dev/null`. Подключение к процессу началось через одну секунду после запуска. Словарь завершился с кодом `0`. [Вставки](fill.in) · [Запросы](queries.in) · [Профиль](sample.txt)

Команда профилирования из корня репозитория использует PID процесса из `$!`.

```sh
/usr/bin/sample "$patricia_pid" 3 1 -file lab1/benchmarks/results/diagnostics/cpu/sample.txt
```

В графе вызовов ветка чтения очередной команды содержит 2 097 из 2 565 выборок главного потока, то есть около 81,8 %. Среди вершин стека больше всего выборок у `_pthread_mutex_firstfit_unlock_slow` (357), `_pthread_mutex_firstfit_lock_slow` (256) и `DYLD-STUB$$__error` (215). `Patricia::find` находится на вершине стека в 214 выборках.
