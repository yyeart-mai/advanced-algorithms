# Лекция 19.09: сбалансированные деревья и куча

- [03_red_black.cpp](03_red_black.cpp): красно-чёрное дерево; простой вариант показывает вставку, шаблонный LLRB также удаление. Ввод: число команд, затем `+ x`, `- x`, `? x`.
- [heap_and_heap_sort.cpp](heap_and_heap_sort.cpp): шаблонная двоичная куча и heap sort для итераторов случайного доступа. Ввод: `n`, затем `n` целых; вывод отсортированного массива.
- [02_treap.cpp](02_treap.cpp): декартово дерево с псевдослучайными приоритетами, вставкой, удалением и поиском. Ввод: число команд, затем `+ x`, `- x`, `? x`.

Исходный разбор деревьев сохранён в [TREES.md](TREES.md). Неявное декартово дерево находится в [лекции 3.10](../lecture_03_10/README.md). Доказательство сбалансированности красно-чёрного дерева требует отдельного теоретического разбора.
