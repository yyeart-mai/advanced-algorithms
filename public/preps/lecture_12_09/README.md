# Лекция 12.09: карманы, внешний ввод, поиск и деревья

| Файл | Что делает | Ввод |
| --- | --- | --- |
| [05_bucket.cpp](05_bucket.cpp) | Сортирует `double` из `[0,1)` по карманам. | `n`, затем `n` чисел. |
| [external_sort.cpp](external_sort.cpp) | Сортирует серии в памяти ограниченного размера, записывает их во временные файлы и сливает через кучу. | `n chunkSize`, затем `n` целых чисел; вывод по одному числу в строке. |
| [binary_search.cpp](binary_search.cpp) | Собственные нижняя и верхняя границы на отсортированном массиве. | `n q`, массив, затем `q` запросов; вывод как в [задаче C](../../homework_1/C.cpp). |
| [bst.cpp](bst.cpp) | Несбалансированное BST: поиск, вставка, удаление и повороты корня. | Число команд; `insert x`, `delete x`, `find x`, `rotate_left`, `rotate_right`. |
| [01_avl.cpp](01_avl.cpp) | AVL: вставка, удаление, поиск, повороты при балансировке. | Число команд; `+ x`, `- x`, `? x`. |

Внешняя сортировка здесь держит открытым один временный файл на серию: при очень большом числе серий потребуется многоступенчатое слияние. Для BST худшая высота — `O(n)`; AVL поддерживает логарифмическую высоту.

`externalSort<T, Compare>` допускает другие тривиально копируемые типы с потоковым вводом/выводом; размер серии ограничивает оперативную память для сортируемых значений. `lowerBound` и `upperBound` работают с итераторами случайного доступа; `BST<Key, Compare>` принимает собственный порядок ключей.

Разбор карманной сортировки — в [BUCKET_SORT.md](BUCKET_SORT.md).
