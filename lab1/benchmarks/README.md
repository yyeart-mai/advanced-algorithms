# Замеры словаря PATRICIA

Матрица состоит из семи сценариев, трёх размеров набора и двух типов ключей. Каждая из 42 комбинаций запускалась пять раз в отдельных процессах.

Замеры проводились на MacBook Pro (`Mac17,2`) с Apple M5 и 16 ГБ памяти, под macOS 26.7.3. Оптимизированная сборка использует Apple Clang 21.0.0 и флаги `-std=c++11 -O2 -Wall -Wextra -Wpedantic`. Из корня репозитория она собирается командой `make -C lab1` и создаёт `lab1/build/dictionary`.

## Входные данные

- Размеры наборов составляют 1 000, 10 000 и 100 000 уникальных ключей. Ключи состоят из 32 строчных английских букв, значения имеют тип `uint64_t`. Наборы вставки сгенерированы с seed `42` [генератором вставок](generate_insert.py).
- Семейство `prefix` получено заменой первых 24 букв на `abcdefghijklmnopqrstuvwx`. Для каждого измеренного размера оставшиеся 8 букв, значения и порядок вставки совпадают со случайным набором.
- Ключи для промахов сгенерированы с seed `43`. Их восьмибуквенные суффиксы уникальны и отсутствуют среди суффиксов ключей вставки. Случайные и префиксные промахи используют одинаковые суффиксы. Все измеренные входы сохранены в `results`.

## Сценарии

`N` обозначает размер набора.

| Сценарий | Что получает словарь | Команд |
| --- | --- | ---: |
| `insert` | Вставка всех ключей в пустое дерево | `N` |
| `lookup-hit` | Заполнение, затем поиск каждого вставленного ключа | `2N` |
| `lookup-miss` | Заполнение, затем поиск отсутствующих ключей | `2N` |
| `erase` | Заполнение, затем удаление всех ключей в порядке вставки | `2N` |
| `mixed` | Заполнение, затем цикл из вставки нового ключа, успешного поиска, промаха и удаления | `2N` |
| `save` | Заполнение, затем `! Save dictionary.bin` | `N + 1` |
| `load` | `! Load dictionary.bin` в пустом процессе словаря | `1` |

У `Save` целевой `dictionary.bin` отсутствовал перед каждым прогоном. Последний проверенный файл каждого набора сохранён как `snapshot.bin` в каталоге `save` или `save-prefix`. Для `Load` копия такого снимка заранее помещена в каталог запуска под именем `dictionary.bin`.

## Измерение времени и памяти

[measure_once.py](measure_once.py) запускает ровно один процесс словаря. Время измеряется монотонными часами `time.perf_counter_ns()` от начала запуска до возврата `os.wait4()`. В интервал входят чтение команд, обработка, запись ответов, файловые операции словаря и завершение процесса. Вход готовится заранее, ответы сверяются после остановки таймера. Из `ru_maxrss` берётся пиковый объём резидентной памяти дочернего процесса в байтах. Для сводки байты делятся на `1 048 576` и записываются в МиБ. Время и RSS представлены медианой и диапазоном от минимума до максимума пяти прогонов.

Рядом с каждым `.in` лежат пять `.out` с ответами и пять `.time` с полями `real_ms`, `max_rss_bytes` и `exit_code`. Например, [вход успешного поиска](results/lookup-hit/lookup-hit-1000/lookup-hit-1000.in), [ответы](results/lookup-hit/lookup-hit-1000/lookup-hit-1000-precise-01.out) и [лог первого прогона](results/lookup-hit/lookup-hit-1000/lookup-hit-1000-precise-01.time).

## Профиль CPU

Утилита macOS `/usr/bin/sample` подключалась к оптимизированному словарю после запуска. На вход подавался один блок из 100 000 вставок и 60 блоков по 100 000 успешных запросов к ключам с общим префиксом. Ответы направлялись в `/dev/null`. Профиль снимался три секунды с интервалом 1 мс. Ветка чтения команд присутствовала в 2 097 из 2 565 выборок главного потока. `Patricia::find` оказалась на вершине стека в 214 выборках.

## Диагностика памяти

**AddressSanitizer.** Отдельная сборка прогнала весь набор проверок CLI, включая 20 000 смешанных команд с seed `20261120`. Код выхода `0`. Для обнаружения утечек использовался отдельный запуск `leaks`, поэтому встроенная проверка утечек ASan была отключена.

**`leaks`.** Инструмент проверял оптимизированную сборку при выходе по `--atExit`. Вход из 21 команды включает оба порядка удаления `a` и `aa`, две замены дерева при загрузке и завершение с тремя ключами. Протокол содержит 189 выделенных блоков, 0 утечек и 0 потерянных байтов, а также сообщение об ограничении на показ содержимого памяти процесса.
