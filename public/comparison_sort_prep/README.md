# Сортировки сравнением

Оба файла — самостоятельные программы C++17. Ввод: `n`, затем `n` целых чисел. Вывод: числа по возрастанию. Пример: `5` и `4 1 4 -2 0` → `-2 0 1 4 4`.

| Файл | Идея | Время | Дополнительная память |
| --- | --- | --- | --- |
| [01_quick.cpp](01_quick.cpp) | Разделение на `<`, `=`, `>` относительно опорного элемента | Среднее `O(n log n)`, худшее `O(n²)` | Стек `O(log n)` благодаря рекурсии по меньшей части |
| [02_merge.cpp](02_merge.cpp) | Рекурсивно сортирует половины и устойчиво сливает их | `O(n log n)` | Буфер `O(n)`, стек `O(log n)` |

Запуск: `c++ -std=c++17 -Wall -Wextra -pedantic 01_quick.cpp -o /tmp/quick && /tmp/quick`. Для второго файла замените имя исходника и исполняемого файла.

При разборе quicksort проследите границы трёх частей на массиве с одинаковыми значениями. При разборе merge sort проверьте, почему `<=` сохраняет порядок равных элементов из левой половины.
