# Запросы на отрезке

Программы работают с индексами от нуля и полуинтервалами `[l, r)`. Ввод: `n q`, затем `n` целых чисел, затем `q` команд. `q l r` печатает сумму. В [дереве отрезков](01_segment_tree.cpp) `s i x` присваивает элементу `x`; в [дереве Фенвика](02_fenwick.cpp) `a i d` прибавляет `d`.

Пример для обоих: `3 2`, `1 2 3`, `q 0 3`, `q 1 2` → `6`, `2`. Построение дерева отрезков — `O(n)`, дерева Фенвика в этой программе — `O(n log n)`; каждый запрос и обновление — `O(log n)`, память — `O(n)`.

Запуск: `c++ -std=c++17 -Wall -Wextra -pedantic 01_segment_tree.cpp -o /tmp/segment && /tmp/segment`. Аналогично для второго файла.

## Обобщённые варианты

`SegmentTreeGeneric<T, Combine>` строится из диапазона **прямых итераторов** и принимает нейтральный элемент: `SegmentTreeGeneric<std::string> st(v.begin(), v.end(), "");`. `Combine` должен быть ассоциативным; порядок элементов сохраняется и для некоммутативной операции. `FenwickGeneric<T>` тоже строится из прямых итераторов: `FenwickGeneric<long long> fw(v.begin(), v.end());`; тип должен поддерживать нулевое значение, `+=` и вычитание. Оба класса используют полуинтервалы `[l, r)`.
