# Карманная сортировка: разбор


В [05_bucket.cpp](05_bucket.cpp) вход ограничен диапазоном `[0, 1)`. Для `n` элементов создаётся `n` корзин; номер корзины — целая часть `x*n`. Каждая корзина сортируется вставками, затем корзины соединяются по возрастанию номера: [лекция Университета Нью-Мексико](https://www.cs.unm.edu/~saia/classes/561-f07/lec/lec7-2x2.pdf).

Для четырёх корзин: `0.12 -> 0`, `0.77 -> 3`, `0.31 -> 1`, `0.25 -> 1`. Индексы рассчитаны как `floor(4*x)`. В корзине 1 порядок `[0.31, 0.25]` нужно исправить на `[0.25, 0.31]`. Одного распределения недостаточно.

При независимом равномерном распределении и `n` корзинах ожидаемое время этой схемы — `O(n)`. Если все элементы попали в одну корзину, внутри неё возможна квадратичная работа вставок; худшее время — `O(n²)`. Память — `O(n)`. Название темы «линейные сортировки» не даёт bucket sort безусловную линейную гарантию: [лекция UNM](https://www.cs.unm.edu/~saia/classes/561-f07/lec/lec7-2x2.pdf), [Princeton, упражнение о равномерном распределении](https://algs4.cs.princeton.edu/51radix/).

Для другого диапазона требуется другая формула корзины. Не отправляй этот пример в задачу с произвольными целыми числами без адаптации. Внутри корзин готовая сортировка не используется.
