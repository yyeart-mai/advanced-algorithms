# Лекция 10.10: префиксные и многопутевые деревья

- [trie.cpp](trie.cpp): шаблонное trie по символам с вставкой, поиском и удалением слова. Команды `+ слово`, `- слово`, `? слово`.
- [compact_trie.cpp](compact_trie.cpp): trie со строковыми метками рёбер; вставка, поиск, удаление с повторным сжатием рёбер. Те же команды.
- [patricia.cpp](patricia.cpp): двоичное PATRICIA для беззнаковых целых фиксированной ширины; хранит только значащие разветвления. Команды `+ x`, `- x`, `? x`.
- [two_three_four.cpp](two_three_four.cpp): 2-3-4 дерево со вставкой и поиском. Команды `+ x`, `? x`. Это B-дерево минимальной степени 2; удаление в том же классе структур показывает [шаблонное B-дерево](../lecture_17_10/04_b_tree.cpp) с `Degree = 2`.

Каждая программа сначала читает число команд, затем команды по строкам; поиск печатает `YES` или `NO`. Определение B-дерева продолжено в [лекции 17.10](../lecture_17_10/README.md). Связь 2-3-4 дерева с красно-чёрным здесь не доказана кодом.

`Trie<Symbol>` принимает диапазоны итераторов по символам, `CompactTrie<CharT>` работает с `basic_string_view<CharT>` и диапазонами символов, `Patricia<UInt>` — с беззнаковым целочисленным типом фиксированной ширины.
