# Подготовка по лекциям

Папки названы по датам из [учебного контекста](../../STUDY_CONTEXT.md); год лекций не указан. Каждый `.cpp` — отдельная программа C++17. Внутри README лекции указаны формат ввода, примеры и ограничения реализации. В старых примерах также сохранены шаблонные варианты с итераторами.

| Лекция | Примеры |
| --- | --- |
| [5.09](lecture_05_09/README.md) | Сортировки сравнением, подсчётом и поразрядная. |
| [12.09](lecture_12_09/README.md) | Карманная и внешняя сортировки, бинарный поиск, BST, AVL. |
| [19.09](lecture_19_09/README.md) | Красно-чёрное дерево, куча и heap sort, декартово дерево. |
| [3.10](lecture_03_10/README.md) | Неявное декартово дерево, дерево отрезков, дерево Фенвика. |
| [10.10](lecture_10_10/README.md) | Trie, compact trie, PATRICIA и 2-3-4 дерево. |
| [17.10](lecture_17_10/README.md) | B-дерево со вставкой, поиском и удалением. |
| [24.10](lecture_24_10/README.md) | Хеширование с цепочками и открытой адресацией; наивный поиск подстроки, префикс-функция, KMP и Z-функция. |

Доказательства асимптотических оценок, сбалансированности и связи 2-3-4/красно-чёрных деревьев остаются теорией лекций; код не заменяет доказательство. «Основная функция препроцессинга» в переданном перечне не названа, поэтому префикс-функция отмечена как дополнительный пример, а не как установленная тема лекции.

Решения задач и их статус — в [архиве](../../SOLVED_TASKS.md).
