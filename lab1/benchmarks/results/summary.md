Во всех случаях используется [measure_once.py](../measure_once.py). Время включает запуск процесса, чтение входа, выполнение всех команд, запись stdout и завершение процесса. Таблица содержит медиану и минимум с максимумом пяти отдельных прогонов. Пиковый RSS переведён из байтов в МиБ делением на 1 048 576.

Вставки подготовлены с seed 42. В семействе `prefix` первые 24 буквы каждого 32-буквенного ключа заменены общим префиксом. Значения и суффиксы согласованы между семействами. Ключи для промахов сгенерированы с seed 43 без пересечений с ключами вставки. В смешанном потоке чередуются вставка, успешный поиск, промах и удаление.

Поиск, удаление, смешанный сценарий и `Save` начинаются с заполнения дерева командами вставки. `Save` в каждом измеряемом запуске пишет в новый `dictionary.bin`. Последний проверенный файл сохранён как `snapshot.bin`. `Load` читает заранее подготовленную копию этого снимка из своего каталога. Её содержимое проверено отдельно поиском всех сохранённых ключей.

Каталоги сгруппированы по сценарию и типу ключей. Для каждого размера набора в одноимённом подкаталоге лежат файл `.in` и пять пар `.out` и `.time` с номерами `01`–`05`.
