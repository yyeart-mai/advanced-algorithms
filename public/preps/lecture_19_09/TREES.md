# Деревья поиска

Каждый файл — отдельная программа C++17. Шаблонные варианты AVL, декартова, красно-чёрного и B-дерева поддерживают вставку, поиск и удаление уникальных ключей. Простые варианты в тех же исходниках сохранены для чтения и реализуют вставку и поиск. Ввод программ: число команд `q`, затем `+ x` (добавить), `- x` (удалить) или `? x` (проверить). Вывод для `?`: `YES` или `NO`.

| Файл | Инвариант | Сложность вставки/поиска |
| --- | --- | --- |
| [01_avl.cpp](../lecture_12_09/01_avl.cpp) | Высоты левого и правого поддеревьев отличаются не более чем на 1 | `O(log n)` |
| [02_treap.cpp](02_treap.cpp) | Ключи образуют BST, псевдослучайные приоритеты — кучу | Ожидаемое `O(log n)`, худшее `O(n)` |
| [03_red_black.cpp](03_red_black.cpp) | Красный узел не имеет красного ребёнка, число чёрных узлов на путях одинаково | `O(log n)` |
| [04_b_tree.cpp](../lecture_17_10/04_b_tree.cpp) | B-дерево минимальной степени 2: узел содержит от 1 до 3 ключей | `O(log n)` уровней при фиксированной степени |

Пример: `5`, `+ 7`, `+ 3`, `? 3`, `? 4`, `? 7` → `YES`, `NO`, `YES`. Запуск из корня репозитория: `c++ -std=c++17 public/preps/lecture_12_09/01_avl.cpp -o /tmp/avl && /tmp/avl`.

Для AVL проверьте последовательности `1 2 3` и `3 1 2`; для красно-чёрного дерева — перекраску дяди и оба вида поворотов; для B-дерева — разделение заполненного корня; для декартова — два независимых порядка ключей и приоритетов. Код `02_treap.cpp` использует фиксированное начальное состояние генератора ради воспроизводимости, а не криптографической случайности.

## Обобщённые варианты

В исходниках есть шаблонные классы `AVLGeneric<Key, Compare>`, `TreapGeneric<Key, Compare>`, `RedBlackGeneric<Key, Compare>` (LLRB) и `BTreeGeneric<Key, Degree, Compare>`. `Key` должен копироваться, `Compare` задаёт строгий порядок. Например, `AVLGeneric<std::string> tree; tree.insert("abc"); tree.erase("abc");`. Метод `copyInorder(std::back_inserter(result))` записывает ключи через **выходной итератор**. Память удалённых узлов в AVL, декартовом и красно-чёрном учебных вариантах освобождается при уничтожении всего дерева.
