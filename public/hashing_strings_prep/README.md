# Хеш-таблицы и строки

- [01_hash_table.cpp](01_hash_table.cpp): множество строк с цепочками. Ввод: число команд, затем `+ слово` или `? слово`; запрос печатает `YES`/`NO`. Ожидаемое время операции при хорошем распределении — `O(|слово| + длина цепочки)`, худшее при коллизиях — линейное по числу строк. Хеш не криптографический.
- [02_kmp.cpp](02_kmp.cpp): поиск всех вхождений непустого образца через префикс-функцию. Ввод: первая строка — образец, вторая — текст; вывод: начальные индексы вхождений, каждый с новой строки. Время `O(|образец| + |текст|)`.
- [03_z.cpp](03_z.cpp): Z-функция строки. Ввод: одна строка; вывод: `z[0] = 0` и остальные значения. Время `O(n)`.

Каждый файл компилируется отдельно: `c++ -std=c++17 -Wall -Wextra -pedantic 03_z.cpp -o /tmp/z && /tmp/z`. Для самопроверки: `aaaaa` даёт Z-массив `0 4 3 2 1`; KMP для `aba` в `ababa` печатает `0` и `2`.
